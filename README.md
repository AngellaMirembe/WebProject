# Nyakasura School Website Project

## Description
This project is a responsive school website developed using HTML, CSS, and JavaScript. The website is designed to provide information about the school, academics and contact details in a clean and user-friendly manner.

## Pages included
1. Home Page (index)
2. About Page
3. Academic Page
4. Gallery Page
5. Contact Page

## Features
1. Responsive Navigation Bar
2. Hero Section
3. Clubs and activities displayed in cards
4. Academics section featuring programs offered and equipment
5. Contact details
6. Footer with contact information

## Technologies Used
- HTML5
- CSS
- JavaScript
